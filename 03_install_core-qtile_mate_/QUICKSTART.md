# Qtile Quick Start

Welcome to the JustAGuy Linux Qtile setup. This file is yours to delete once you're comfortable.

## The one keybind to remember

**`Super + /`** — opens a searchable menu of every keybind. When in doubt, press it.

## Essentials

| Key | Action |
|---|---|
| `Super + Return` | Terminal (kitty) |
| `Super + Space` | App launcher (rofi) |
| `Super + b` | Browser |
| `Super + f` | File manager |
| `Super + e` | Text editor (geany) |
| `Super + q` | Close focused window |
| `Super + 1-0, -, =` | Switch to group 1-12 |
| `Super + Shift + 1-0, -, =` | Move window to group 1-12 |
| `Super + Arrow` / `Super + j/k` | Focus windows |
| `Super + Shift + Arrow` / `Super + Shift + j/k` | Move windows |
| `Super + Ctrl + Arrow` | Resize window |
| `Super + Tab` | Cycle layouts |
| `Super + Shift + l` | Layout menu |
| `Super + Shift + t` | Theme switcher (12 themes) |
| `Super + Shift + space` | Toggle floating |
| `Super + x` | Power menu |

## Layout

- **Main config:** `~/.config/qtile/config.py`
- **Scripts:** `~/.config/qtile/scripts/`
- **Autostart:** `~/.config/qtile/scripts/autostart.sh`
- **Theme switcher:** `~/.config/qtile/scripts/thememenu` (12 themes available)
- **Theming:** `themes/`, `rofi/`, `dunst/`, `picom/`
